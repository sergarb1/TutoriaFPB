3. FLUJO TÉCNICO DE TRABAJO (cómo se hace una unidad)
-------------------------------------------------------------------------------
- Directorio de trabajo: C:\Users\serga\Desktop\TutoriaFPB (NO el Ofimatica).
- Tras CUALQUIER edición de contenido:
      npm run check   # validador (debe dar 0 errores)
      npm run build   # build estático
  Los DOCX ya los regenera el CI solo; solo usa `npm run docx` si quieres
  comprobarlo en local (requiere Pandoc 3.8.3 en PATH).

- DIAGRAMAS EXCALIDRAW (1 por ficha):
  1. Servidor de canvas en PUERTO 3001. Cada comando CLI lleva delante:
        $env:EXPRESS_SERVER_URL = 'http://127.0.0.1:3001'
     Si no responde, levántalo con: npx -y mcp-excalidraw-server (skill
     excalidraw-skill disponible).
  2. Escribe el JSON del diagrama con la herramienta write (UTF-8). NUNCA con
     PowerShell Get-Content (rompe los acentos).
  3. clear --yes  →  add (el JSON).
  4. Verificar: en C:\Users\serga\Desktop\PresentacionesEducativas ejecuta
        node verify-excalidraw.mjs <ruta\salida.png> 1200 700
     y corrije desbordes (vuelve al paso 2-3 con el JSON ajustado).
  5. Exportar SVG + PNG --scale 2 → public/img/NN-nombre/ + copiar el JSON a
     public/img/fuentes/NN-nombre-xx.excalidraw.
  6. Insertar en la ficha: ![...](/TutoriaFPB/img/NN-nombre/xx.svg)
     dentro de <div class="ficha-img">.

  PALETA del proyecto (diagramas): #e3edff/#2563eb (azul), #d9f6f3/#00897b
  (teal), #fff4d9/#e67e22 (ámbar), #efe7fd/#7c4dbc (violeta),
  #fde8e8/#c0392b (rojo). fillStyle solid, roundness type 3, fontSize 13-17
  en cajas (22-24 en títulos), saltos de línea con \n explícitos.

- REGLAS DE CONTENIDO (las chequea el validador, pero mejor no pisarlas):
  · Frontmatter: si title/description llevan DOS PUNTOS, ENTRECOMILLAR SIEMPRE
    (es el error que más ha roto el build).
